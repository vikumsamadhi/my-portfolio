# Vikum Samadhi — Software Projects

A lightweight, responsive portfolio site for selected public repositories.

## Website

[Open the portfolio](https://vikumsamadhi.github.io/my-portfolio/)

## Projects featured

- [Hardware Inventory System](https://github.com/vikumsamadhi/HardwareInventorySystem) — VB.NET Windows Forms inventory tool with barcode lookup and Excel workbook storage.
- [Paddy Stock Manager](https://github.com/vikumsamadhi/Paddy_Stock_Manager) — React project described as a stock management tool for a mill.
- [Recipe Mobile App](https://github.com/vikumsamadhi/Recipe_mobile_app) — React Native mobile app focused on recipes.
- [Recipe Login App](https://github.com/vikumsamadhi/login_App) — React Native login application for a recipe app.

## Deployment

GitHub Pages serves the static site from the root of the `main` branch. The site uses plain HTML and CSS and has no build step.
