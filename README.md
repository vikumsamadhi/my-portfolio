## Graphic Design

The site links to [Vikum's Behance profile](https://www.behance.net/vikumsamadhi). Individual artwork will be featured after the project details and assets are verified and supplied.

## Implementation

The site is plain HTML and CSS with no build step, external font dependency, or JavaScript requirement. It is designed for GitHub Pages and includes keyboard focus styling, a skip link, semantic landmarks, responsive layouts, and reduced-motion support.

GitHub Pages serves the site from the root of the `main` branch.
